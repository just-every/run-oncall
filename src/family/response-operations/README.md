# Response operations domain

Retained coordination, authenticated admission, incident history and reviewed handoff semantics live here. Scheduling resolves IANA calendar-day boundaries and explains coverage without delivery. Historical synthetic receipts/jobs remain strictly validated for upgrades and archives; job creation, dispatch and timer resume have been removed. The root edition owns authentication, relational D1 publication, operator commands and the interface. No chat, model or delivery provider is a critical-state dependency.
