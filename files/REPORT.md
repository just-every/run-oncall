2. Documented source shape, checked without an account

Oncall’s bundle is a transport wrapper around saved official responses. CloudWatch is a distinct receiving door. The fetched [PagerDuty CloudWatch guide](https://docs.pagerduty.com/integrations/amazon-cloudwatch-integration-guide) specifies an SNS HTTPS subscription to `https://events.pagerduty.com/x-ere/[YOUR_INTEGRATION_KEY_HERE]`, with **raw message delivery unchecked** and automatic subscription confirmation. It sends ALARM and OK transitions. Merely retaining an integration called “CloudWatch,” or changing its destination to an Events v2 JSON endpoint, does not ingest the SNS envelope.

The [AWS SNS notification shape](https://docs.aws.amazon.com/sns/latest/dg/http-notification-json.html) is `{Type,MessageId,TopicArn,Subject?,Message,Timestamp,SignatureVersion,Signature,SigningCertURL,UnsubscribeURL}`; `Message` is a JSON-encoded CloudWatch message. [Subscription confirmation](https://docs.aws.amazon.com/sns/latest/dg/http-subscription-confirmation-json.html) adds `Token` and `SubscribeURL`. Verify the [documented signatures](https://docs.aws.amazon.com/sns/latest/dg/sns-verify-signature-of-message.html), including supported version handling, before confirming or accepting anything. The [CloudWatch documented payloads](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/Notify_Users_Alarm_Changes.html) include metric, composite and current log-alarm variants. Their exact field inventory appears below. An account export does not contain the AWS subscription or alarm configuration by implication; separately supply synthetic AWS evidence with explicit provenance, or report it missing.

3. Field-by-field behavior on inspected main

**M** means copied to an imported target, still paused/inactive; it never means login or paging. **L** means a named transformation or an incomplete semantic conversion. **D** means absent from operational receiving records, even when original bytes survive in the journal. **R** means the whole relevant object or file is refused. Retaining original bytes avoids erasing evidence; it does not complete migration. Nested references share `{id,type,summary,self,html_url}`: an `id` used for a relationship is M, its discriminator is validated where noted, and summary/URLs are D as operating semantics, with a provenance display place rather than a new control. URLs are never fetched by importing them.

The fields are scoped to the fetched classic schemas and documented payloads. Data-dependent dictionaries such as alert details and changesets cannot have a finite global list: enumerate every concrete leaf and JSON pointer in each actual input, including unknown fields. The present importer does not yet produce that exhaustive leaf ledger. Container-level refusals below drop every named child from operating behavior, rather than silently claiming those children mapped.
