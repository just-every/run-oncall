# Local onboarding

Run `npx -y @runeditrun/rer dev just-every/run-oncall` (set up only: `npx -y @runeditrun/rer setup just-every/run-oncall`; without Node: `curl -fsSL https://runeditrun.com/install.sh | sh -s -- dev just-every/run-oncall`), then finish the application setup screen to confirm the local owner. Repeated setup keeps the owner, secrets and data. Local setup requests no provider credential. To host coordination for your team, prepare a real owner mailbox, supply your Cloudflare and remote-mail credentials privately and run `rer deploy`; see [Install and run](docs/install.md#host-for-your-team). The command claims the owner automatically and retires its setup token. Sign in at the hosted app address with an emailed link. Paging stays OFF alongside the existing pager. Coordination needs no standby; release 2 paging and independent standby are not built. Remove the hosted installation with the same Cloudflare credentials using `rer deploy --remove --yes`, which verifies the recorded resources are gone.
