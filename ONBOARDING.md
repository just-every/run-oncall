# Local onboarding

Run `npx -y @runeditrun/rer dev just-every/run-oncall` or use the [Run page](https://run-oncall.com/run). Open the private `RER_OPEN` link and select **Finish setup** to confirm the local owner. If you run `rer setup` by itself, it prints `RER_SETUP_READY` with a loopback address and stops its temporary app. Run `rer dev` from the checkout to get the private local link. Repeated setup keeps the owner, secrets and data.

To host coordination for your team, follow [Getting started](docs/getting-started.md#host-for-your-team). Prepare the owner locally, then deploy using Cloudflare credentials and `MAIL_PROVIDER=none` in your private deploy file. Deployment claims the owner and retires the setup token. Run `rer signin` from the deploying checkout to get the private hosted owner link. You can also [configure email links](docs/getting-started.md#get-a-sendgrid-key-and-verified-sender-for-email-links). Paging stays OFF alongside the existing pager. Coordination needs no standby. Remove the hosted installation with the same Cloudflare credentials using `rer deploy --remove --yes`, which verifies the recorded resources are gone.
